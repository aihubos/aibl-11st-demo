# AI빌더스랩 소개 홈 — 종합몰 스타일 수업 예제

> ⚠️ **수업 예제용 더미 데이터입니다.** 강의·가격·후기·인물·회사 정보는 모두 가상이에요.
> 국내 종합몰(11번가)의 화면 스타일을 **참고**해 만들었을 뿐, 해당 회사와 **아무런 제휴 관계가 없으며** 로고·상표·이미지를 사용하지 않았습니다.

## 무엇인가요?
비개발자를 위한 AI 교육 프로그램 "AI빌더스랩"을 **쇼핑몰처럼** 소개하는 한 장짜리 홈페이지 예제예요.
빨강 강조색, 흰 헤더, 굵은 가격 숫자, 촘촘한 상품 카드 같은 종합몰 디자인 규칙을 연습하는 용도입니다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 (섹션 14개) |
| `styles.css` | 디자인 (색·글꼴·간격·반응형) |
| `data.js` | 더미 데이터 (강의, 타임딜, 후기 등) — **여기 값만 바꾸면 화면이 바뀌어요** |
| `app.js` | 동작 (검색, 찜, 장바구니 숫자, 타이머, 배너, 모달) |
| `tests/check.mjs` | 정적 점검 스크립트 |

## 사용 방법
1. **그냥 열기**: `index.html`을 더블클릭하면 브라우저에서 열려요.
2. **로컬 서버로 열기(추천)**: 터미널에서 `python3 -m http.server 8000` 실행 → 브라우저에서 `http://localhost:8000`
3. **점검하기**: `node tests/check.mjs` → 모두 `✅ PASS`면 성공

## 연습 아이디어
- `data.js`에서 강의 제목·가격을 바꿔 보세요. 할인율(%)은 자동 계산돼요.
- `styles.css` 맨 위 `--color-primary-500` 값을 바꾸면 전체 강조색이 바뀌어요.
